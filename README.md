---

## 🧱 What's On The Page

- **Navbar** — Logo on the left, nav link on the right, with a bold yellow background
- **Hero Section** — Two-column layout with a headline, description, a call-to-action button, and an image

---

## ✨ Features

- **Responsive Design** — collapses to a single-column layout on screens smaller than 768px
- **Smooth Scroll** — enabled via `scroll-behavior: smooth`
- **Hover Button Effect** — the CTA button transitions to white with a scale animation on hover
- **External Link** — the button opens a YouTube link in a new tab

## 🚀 How to Run

1. Download or clone this repository
2. Make sure the image file is in the same folder as `index.html`
3. Open `index.html` in your browser — that's it!
